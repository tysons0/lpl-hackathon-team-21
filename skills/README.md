# Skills

Project knowledge for coding agents. The original skills document the AWS, matching, and agentic architecture. The UI skills below add current frontend design and implementation guidance for the Vite app in `web/`.

## UI skills

- [UI Skill 13: Accessible Design Systems](ui-skill-13-accessible-design-systems.md) — tokens, semantic controls, keyboard and screen-reader support, accessible advisor and chat patterns.
- [UI Skill 14: Responsive Layouts and Interaction Patterns](ui-skill-14-responsive-interaction-patterns.md) — adaptive layouts, state modeling, touch and keyboard behavior, reduced motion.
- [UI Skill 15: Fast, Stable Data Displays](ui-skill-15-performance-and-data-display.md) — responsive loading, Core Web Vitals, metrics, charts, and trustworthy comparisons.

## Applying these skills

Use these as design and implementation references when changing `web/src/main.js` or `web/src/style.css`. They are tailored to the current vanilla JavaScript frontend; React links are conceptual references for state modeling, not instructions to add React.
